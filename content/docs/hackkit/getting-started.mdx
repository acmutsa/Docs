## Prerequisites

- [pnpm (v8 or higher)](https://pnpm.io/installation)

## Installation

<Steps>
  <Step>
    ### Clone the repository
    ```bash
    git clone https://github.com/acm-utsa/hackkit.git && cd hackkit
    ```
  </Step>
  <Step>
    ### Install dependencies
    ```bash
    pnpm install
    ```
  </Step>
  <Step>
    ### Run the application
    ```bash
    pnpm run dev
    ```
  </Step>
</Steps>
